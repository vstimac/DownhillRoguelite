# Tuntun Sahur

Supplied by the director as `tuntuntun.stl` (Blender 4.0 export, ~500k triangles), added 2026-11-09.
Decimated to ~15k triangles, stood up (head +Y, face -Z), feet at the origin, 1.97 m tall, one wood
material, exported as `tuntun.glb` (Blender 5.1). The bat is part of the mesh; he has no skeleton, so
`wildlife/TuntunSahur.cs` animates him by leaning the whole log. The original STL is not in git.
