# Quaternius — Farm Animals Pack

CC0 1.0 (see LICENSE.txt). By Quaternius. Added by the director on 2026-11-06.

**Use in Godot:** `FBX/` (imports with skeleton and animations; no Blender needed).
Models: Cow, Horse, Llama, Pig, Pug, Sheep, Zebra.
Clips: Idle, Walk, WalkSlow, Run, Jump, Death. Imported clip names carry the armature prefix, e.g. `Armature|Walk`.

`source/` (ignored by Godot through `.gdignore`): the original `.blend` files, OBJ copies and the preview GIF.
