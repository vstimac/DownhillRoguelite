# addons

Third-party Godot addons.

## nobodywho

Runs local language models (LLM chat, speech-to-text, text-to-speech, embeddings) inside Godot as a GDExtension. Installed by the director on 2026-11-06. Licence: `nobodywho/LICENSE`.

Its prebuilt libraries (`*.dll`, `*.so`, `*.dylib`, `*.pdb`, about 1.3 GB in total) are **not in git**: each is about 140 MB, over GitHub's 100 MB file limit. On a fresh clone, reinstall NobodyWho (Godot Asset Library, or its GitHub releases) into `addons/nobodywho/`, keeping the committed `nobodywho.gdextension`. Requires Godot 4.6 or newer.
