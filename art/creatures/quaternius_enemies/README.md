# Quaternius — Easy Animated Enemy Pack (Jan 2019)

CC0 1.0 (see LICENSE.txt). By Quaternius. Added by the director on 2026-11-06.

**Use in Godot:** `FBX/` (imports with skeleton and animations; no Blender needed).
Models: Frog, Rat, Snake, Snake_angry, Spider, Wasp.
Clips include Idle, Walk, Run, Jump, Attack, Death (Wasp: Flying). Imported clip names carry the armature prefix, e.g. `FrogArmature|Frog_Idle`.

`source/` (ignored by Godot through `.gdignore`): the original `.blend` files and OBJ copies, for editing in Blender.
