DOWNHILL ROGUELITE - playtest

FIRST: extract the whole zip (right-click the zip > Extract All), then run DownhillRoguelite.exe
from the extracted folder. Keep the files in this folder together.

Nothing else to install: .NET is built into the game.
Needs Windows 10 or 11 (64-bit) and up-to-date graphics drivers (Vulkan) from NVIDIA, AMD or Intel.

Start: DownhillRoguelite.exe
Race:  "Race - same mountain.bat" (everyone gets the same mountain; your first life counts, deepest wins)

You carry a pack down an endless mountain. Reach the next station (a fire with a beam of light)
before night. Eat, drink, rest. A heavy or badly packed load tips you over: lean against it.

WASD walk - Shift sprint - C careful steps - Space jump - Mouse look
Left/right mouse: lean left/right, both: brace
E pick up / sleep / choose a boon - F eat - Q drink - 1-9 + V hotbar
I inventory (eat, drink, wear clothes, mend at stations) - J journal - M map
Enter: talk with your companion (optional: put the model file in a "Models" folder next to this
folder; see the release page) - Tab: repack at a station
Esc: pause and Options (volume, video, controls) - R twice: give up (new mountain)

Headphones recommended.
If it crashes, send this file: %APPDATA%\Godot\app_userdata\Downhill Roguelite\logs\godot.log
(paste that path into the Explorer address bar to open it)
